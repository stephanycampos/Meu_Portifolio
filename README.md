Navbar com Animação de Bolha - Projeto Web

Este projeto cria uma navbar responsiva com animação de bolha, onde o menu aparece com uma animação circular suave ao clicar no botão hambúrguer. 

Utilizei para o projeto:

- HTML: Estrutura do menu com botão hambúrguer e links de navegação.
- CSS: Animação circular no menu com clip-path e responsividade utilizando @media queries.
- JavaScript: Lógica para alternar a classe .active, exibindo o menu com a animação de bolha.
